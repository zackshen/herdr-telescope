# Changelog

All notable changes to this project will be documented in this file.

## [0.1.2] - 2026-08-20

### Added

- Generate CHANGELOG.md from conventional commits

### Fixed

- Paint the telescope before scanning huge trees

### Added

- List live workspaces in the telescope for name search

### Changed

- Recommend prefix+p as the default keybinding
- Recommend cmd+p as the default keybinding

### Fixed

- Submit named prompts on Enter instead of waiting for EOF

### Added

- Herdr-telescope — fzf command telescope (native + plugin actions + file finder)
- @<query> shortcut jumps straight to the file finder
- Live @ file switch, opaque popup, and open with $EDITOR
- Live / content search with bat-highlighted preview
- Install prebuilt binaries from GitHub Releases
